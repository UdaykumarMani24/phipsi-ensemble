UniProt position = PDB residue number + offset. Use the file upload if the online lookup fails.

One NMR entry: all its models form the ensemble. Several IDs of the same protein: each entry (and each of its models) is one ensemble member; set the chain so numbering lines up. Max 30 IDs.
